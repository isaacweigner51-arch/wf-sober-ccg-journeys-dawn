# WF Sober CCG v0.1.0 — 120 Card Launch Set

- Journey’s Dawn expanded from 80 to 120 cards.
- Added 40 synergy-focused cards: 8 Hope, 8 Courage, 8 Serenity, 8 Purpose, and 8 Neutral.
- Added Epic rarity as a two-copy build-around tier.
- Epic crafting cost: 900 Recovery Vials. Duplicate value: 275 Vials.
- Main menu and collection counters now display 120 cards.
- Pack rarity logic now supports Epic pulls.
- New cards currently reuse existing full-card artwork slots so they display correctly while dedicated art is produced.
