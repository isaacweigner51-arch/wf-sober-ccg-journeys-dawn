# v0.7.5 — Developer Meta Gauntlet

- Rebuilt DEV Meta into four distinct owner-only class meta decks.
- Courage Meta: Rally/board-flood tempo built around Rally the Free.
- Hope Meta: resilient midrange built around Beacon of Hope and Second Chance.
- Serenity Meta: Ward/control built around Inner Peace and Calm After the Storm.
- Purpose Meta: Sponsor/Walking Free value-combo built around Strategic Collapse.
- Final Boss remains a separate strongest-legal benchmark deck.
- Removed the hidden seven-tap developer unlock variables and handler.
- Developer access now uses only the authenticated AccessManager role/PIN flow.
