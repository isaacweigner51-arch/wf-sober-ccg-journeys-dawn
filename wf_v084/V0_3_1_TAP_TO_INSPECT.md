# WF Sober CCG v0.3.1 — Tap-to-Inspect Cards

- Removed floating information buttons from cards.
- Tapping any visible card opens the full card-details overlay.
- Hand cards include a PLAY CARD action inside the details overlay.
- Friendly battlefield cards include SELECT ATTACKER.
- Enemy battlefield cards include TARGET FOLLOWER.
- Card details overlay blocks all underlying card input.
- Hand drag-to-reorder remains available.
- Updated Android version code to 31 and version name to 0.3.1.
