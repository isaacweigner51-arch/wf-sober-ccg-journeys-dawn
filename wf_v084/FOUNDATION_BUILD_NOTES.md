# WF Sober CCG v0.5 — Foundation Build

Implemented in this build:
- 80-card Journey's Dawn database (`data/cards.json`, JD-001 through JD-080)
- Four class Signature Platinums plus neutral Signature Platinum **The Sponsor**
- 40-card deck builder with enforced copy limits
- Collection ownership and missing-card silhouettes
- Recovery Dust conversion for excess copies
- Pack inventory, 5-card openings, Silver+ guarantee, approximately 1-in-11 Platinum chance, and 40-pack Platinum guarantee
- Recovery Road challenge screen with gold rewards and 500-gold first-clear bonus for Recovery Master
- First-class selection grants a starter collection, prebuilt deck, and five packs
- Persistent profile data stored in `user://journeys_dawn_profile.cfg`
- Existing battle, leaders, living-card visuals, Sponsor battle mechanic, and store preserved

Copy limits:
- Bronze: 3
- Silver: 3
- Gold: 2
- Legendary: 1
- Signature Platinum: 1
