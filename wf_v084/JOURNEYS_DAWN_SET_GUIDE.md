# Journey's Dawn — Set Guide

## Official name
WF Sober CCG: Journey's Dawn

## Tagline
Every legend begins with a single step.

## Expansion symbol
A rising sun over the horizon. The in-game prototype uses the ☀ symbol with the set code **JD**.

## Set structure
- 16 Serenity cards
- 16 Courage cards
- 16 Purpose cards
- 16 Hope cards
- 12 Universal cards
- 76 unique cards total

## Collector convention
Suggested card numbering:
- JD-001 through JD-076 for the full set
- JD-P001 through JD-P005 for Platinum collector references
