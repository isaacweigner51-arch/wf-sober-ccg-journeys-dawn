# WF Sober CCG: Journey's Dawn

**Journey's Dawn** is the first 76-card expansion for WF Sober CCG.

Tagline: **Every legend begins with a single step.**

## Included
- 76-card first set
- 40-card decks
- Serenity, Courage, Purpose, Hope, and Universal cards
- Bronze, Silver, Legendary, and Platinum rarities
- Three one-use Evolution cards per player
- Universal play-point ramp cards
- AI battle demo
- Deck builder, collection, and Journey's Dawn booster preview

## Expansion identity
- Name: Journey's Dawn
- Set code: JD
- Symbol: rising sun / ☀
- Platinum collector range: JD-P001 onward

Open `project.godot` with Godot 4 and press F5.
