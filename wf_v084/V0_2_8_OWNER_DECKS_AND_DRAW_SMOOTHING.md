# v0.2.8 — Owner Deck Isolation & Draw Smoothing

- Developer Meta and Final Boss decks are now owner-only in both UI and launch guards.
- The computer now uses legal class prebuilt decks instead of developer meta decks.
- Added equal curve-smoothing for player and AI decks. The first eight cards contain a healthy low/mid/high-cost mix when the deck has those cards available.
- Opening hands can no longer repeatedly consist almost entirely of 7+ cost cards.
- Second Chance reorders the remaining deck with the same curve-smoothing rule.
- Android version code increased to 28.
