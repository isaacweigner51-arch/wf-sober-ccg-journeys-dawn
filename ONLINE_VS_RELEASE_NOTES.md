# Online VS Private Room Prototype

- Removed pass-and-play from the main menu.
- Added separate-device Host Match and Join Match screens.
- Added six-digit private room codes.
- Added class selection and ready synchronization.
- Added an included WebSocket relay server for private testing.
- Added synchronized Second Chance, Momentum, turns, health, boards, hands, decks, Relapse Zones, and evolution state.
- Added opponent disconnect handling.
- Android INTERNET permission remains enabled.

This is a trusted-friends private-match prototype. It uses a relay and state synchronization; ranked anti-cheat validation is not part of this build.
