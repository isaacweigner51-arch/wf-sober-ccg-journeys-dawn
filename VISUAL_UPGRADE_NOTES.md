# Visual Upgrade Build

This version moves the project away from procedural placeholder art and toward the selected ornate fantasy direction.

## Included
- Illustrated battlefield background integrated into the playable match.
- Illustrated leader portraits.
- Sixteen illustrated card-art crops assigned deterministically across all cards.
- Illustrated cards used in the home, deck builder, collection, and pack-opening previews.
- Existing 120-card Journey's Dawn catalog, 40-card decks, Universal ramp, AI, and three-card Evolution system remain playable.

## Next production-quality step
Replace the temporary shared art pool with one original portrait per card. The code already loads external PNG art, so future replacements only require changing image files rather than rewriting card logic.
