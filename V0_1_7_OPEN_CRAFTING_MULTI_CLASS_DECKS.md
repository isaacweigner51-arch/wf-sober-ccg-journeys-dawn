# v0.1.7 — Open Crafting & Multi-Class Decks

- Players may craft any craftable card from any class.
- Crafting is no longer presented as tied to the player's starter class.
- Every class now keeps its own separately saved deck.
- Switching classes in Deck Builder no longer leaves the previous class's cards trapped in the active list.
- Existing single-deck saves migrate automatically into their original class slot.
- Normal class deck rules remain: one class plus Neutral, exactly 40 cards, and rarity copy limits.
