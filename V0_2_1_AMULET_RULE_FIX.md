# WF Sober CCG v0.2.1 — Amulet Rule Fix

- Daily Progress is now a true 2 PP Gold Amulet with no Attack or Defense.
- Amulets cannot attack, be attacked, evolve, or take follower/combat/board damage.
- Generic board clears skip Amulets.
- Only effects explicitly coded to target an Amulet can remove one.
- Card views, Second Chance, and inspection screens show AMULET instead of 0/0 stats.
- Android version code increased to 21.
