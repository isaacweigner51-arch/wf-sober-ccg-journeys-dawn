# v0.2.9 Class Training Battles

- Replaced the click-through Academy entry flow with a four-class breakdown screen.
- Players choose Courage, Hope, Serenity, or Purpose before training.
- Each class page explains its permanent resource: Resolve, Hope, Peace, or Progress.
- Selecting a class launches a real battle using that class prebuilt deck against a legal computer prebuilt deck.
- A battle overlay gives class-specific objectives.
- Winning the first class training battle marks Academy complete and grants 500 Gold once.
- Additional classes can be replayed for practice without repeating the 500 Gold reward for the same class.
